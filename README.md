# Keyberth 사용자 가이드

Keyberth는 AI Micro 키패드로 Mac의 대화와 터미널을 제어하는 메뉴 막대 앱입니다. 메뉴 막대에서 앱을 고르고 1–6번 키로 최근 세션을 엽니다. 키에 들어오는 조명을 보면 어떤 세션이 실행 중이고 어디에 입력이 필요한지 알 수 있습니다.

## 처음 사용하기

1. Apple Silicon Mac에서 최신 릴리스의 **macOS-arm64.dmg**를 다운로드합니다. [최신 버전 다운로드](https://github.com/kyungtaek/keyberth/releases/latest)
2. DMG를 열고 **Keyberth**를 **Applications(응용 프로그램)** 폴더로 드래그한 뒤, 응용 프로그램 폴더에서 실행합니다.
3. 권한 안내가 뜨면 **시스템 설정 열기**를 누릅니다. **개인정보 보호 및 보안 → 손쉬운 사용**에서 Keyberth를 켜고 앱으로 돌아와 **다시 확인**을 누릅니다.
4. **Universal Agent 0.2.18** 펌웨어가 설치된 AI Micro를 USB로 연결합니다. Keyberth 창 하단에서 USB 연결 상태를 확인합니다.
5. 사용할 앱을 앞으로 가져오면 해당 앱의 예외가 적용됩니다. 일반 클릭은 키 매핑 창을 엽니다. 슬롯별 대화와 상태는 이 창의 **최근 세션** 탭에서 확인합니다.

## 개발 빌드의 기기 펌웨어

Mac 본체에 AI Micro를 USB로 연결하고 **기기 설정 → 펌웨어**에서 키버스-펌웨어 설치, 업데이트, 공장 초기화 또는 정품 롤백을 선택합니다. 키버스-펌웨어 0.4.5는 별도 OTA 파티션에서 실행됩니다. 재시작하거나 전원을 껐다 켜도 키버스로 부팅합니다. **정품으로 복귀**를 선택하면 이후에는 Universal Agent로 부팅합니다. 첫 설치 시 정품의 절전 시간과 부저 설정을 가져옵니다. **기기 설정**에서 USB로 값을 읽거나 바꿀 수 있습니다. 버튼과 노브를 조작할 때는 부저가 울리지 않습니다. 모니터링 중인 세션이 입력 요청 또는 완료 상태로 바뀌면 설정한 음량으로 알립니다. Bluetooth 페어링은 각 펌웨어에서 별도로 관리합니다. [펌웨어 안내](firmware/README.md)

## 글로벌 키와 앱별 키

키 매핑 창은 **글로벌 기본**에서 시작합니다. 먼저 공통 키를 배정하세요. **앱별 예외**에서 등록된 앱, 실행 중인 프로세스 또는 응용 프로그램 파일을 선택한 뒤 그 앱에서 바꿀 키만 저장합니다. 나머지 키는 글로벌 설정을 따릅니다. **글로벌 설정 따르기**로 예외를 해제할 수 있습니다. 포커스 자동 전환은 처음 설치할 때 켜져 있으며 **기기 설정 → 기기**에서 끌 수 있습니다. 이전에 저장한 켬·끔 선택은 유지됩니다.

Codex Desktop, T3 Code, cmux에서는 **앱별 예외 → 프로세스 선택 → 프리셋 적용**으로 추천 기능 키를 한 번에 저장할 수 있습니다. 1~6번은 건드리지 않으며, 직접 지정한 키와 명시적으로 글로벌 상속을 선택한 키도 유지합니다.

1~6번의 글로벌 기본값은 **통합 최근 세션**입니다. 키를 누르면 해당 세션을 소유한 앱과 대화 또는 터미널 패널이 열립니다. 앱별 최근 목록을 원하면 개별 앱 설정에서 **최근 세션**을 선택하세요. 자동 전환 중 배정이 달라지면 하단 HUD의 키보드 그림이 바뀐 키를 강조하고 대표 기능을 최대 세 개 표시합니다.

**Orca**는 앱 관리에서 추가하고 키 매핑에서 프리셋을 적용하세요. [Orca 전체 기능 및 초기 배정](docs/orca-actions.md)

## 키맵 선택과 편집

- **메뉴 막대 아이콘 우클릭**으로 대상 앱을 선택하거나 **포커스된 앱으로 자동 전환**을 켜고 끕니다. 현재 선택은 화면 하단의 HUD에서 확인합니다. 같은 메뉴에서 **앱 자동 전환 시 HUD 표시**를 끄면 포커스에 따른 키맵 전환은 그대로 두고 해당 HUD만 숨깁니다. 기본값은 켬이며, 수동 키맵 선택과 오류 알림은 그대로 표시됩니다.
- **메뉴 막대 아이콘 우클릭 → 키 매핑**을 엽니다. 앱을 고르고 키보드 그림에서 바꿀 키나 방향을 클릭합니다. 기능을 고르거나 **단축키**에서 ⌘·⌃·⌥·⇧와 기본 키를 조합한 뒤 **저장**을 누릅니다. 노브의 시계·반시계 회전과 클릭도 앱마다 따로 설정합니다.
- **기능 → 시스템 동작**에서 미션 컨트롤, 음량, 미디어 재생, 전체 화면, 창 배치, 마우스 휠 상하 스크롤, 페이지 업·다운을 고를 수 있습니다. **앱 전환**에서 즐겨찾기한 앱을 배정하면 실행 중인 앱은 앞으로 가져오고 닫힌 앱은 실행합니다. 즐겨찾기는 기기 설정에서 실행 중인 앱이나 응용 프로그램 파일을 선택해 추가합니다. **다음 즐겨찾기 앱**과 **이전 즐겨찾기 앱**은 등록한 앱을 이름순으로 순환합니다. 이 동작을 글로벌 키맵의 노브 양방향에 배정하면 앱이 바뀐 뒤에도 같은 노브로 계속 전환할 수 있습니다.
- cmux, T3, Codex의 **앱 메뉴**는 실행 중인 앱에서 읽습니다. 메뉴가 바뀌면 키 매핑 화면에서 새로 고침하세요. 현재 창에서 사용할 수 있는 명령만 실행됩니다.
- **기기 설정 → 앱 키맵**에서 내장 프로필을 추가하거나 Mac에 설치된 응용 프로그램을 선택해 단축키를 배정할 수 있습니다. 삭제하면 해당 앱의 키 배정도 지워집니다.
- **기기 설정 → 키맵 파일 → JSON 내보내기**로 배정을 백업합니다. 다른 Mac에서는 **JSON 가져오기**를 선택합니다. 파일에 포함된 앱의 배정이 적용됩니다.

## 기본 키로 무엇을 할 수 있나요?

| 키 | cmux | T3 Code 0.1.7 | Codex Desktop |
| --- | --- | --- | --- |
| 1–6 | 최근 터미널 열기 | 최근 세션 열기 | 최근 대화 열기 |
| 방향키 | 상하좌우 이웃 패널로 포커스 이동 | 아래 터미널 전환 · 오른쪽 사이드 패널 전환 | 위 계획 모드 · 아래 사이드바 · 좌우 이전/다음 페이지 |
| 7 | 새 워크스페이스 | 새 대화 | ChatGPT의 내 Dots 열기 |
| 8 / 9 | 현재 대화의 Feed 요청 승인 / 거부 | 현재 요청 승인 / 현재 세션 정리 | 현재 요청 승인 / 거부 |
| 10 | 오른쪽 사이드 패널 열기 | 현재 대화 포크 | 현재 대화 포크 |
| 11 | 스페이스, 길게 누르면 반복 | 누르고 macOS 받아쓰기 | 누르고 작성창에 받아쓰기 |
| 12 | 오른쪽 분할에서 대화 포크 | 현재 응답 중단 | **새 대화** |
| 13 | Enter | 보내기 | 보내기 |

**cmux**는 다른 앱을 사용 중이어도 세션 키를 누르면 해당 터미널을 전면에 열고 선택한 분할 패널을 잠깐 강조합니다. 8·9번은 현재 대화의 대기 요청을 한 건으로 식별할 수 있을 때 동작합니다.

**T3 Code와 Codex Desktop**에서 11번을 누른 동안 말하면 작성창에 입력됩니다. 키를 떼면 받아쓰기를 종료하고 13번을 누르면 전송합니다. T3 Code에서는 먼저 **시스템 설정 → 키보드 → 받아쓰기**를 켜세요.

**Codex Desktop**에서 10번을 누르면 현재 대화 메뉴에서 같은 작업공간으로 포크합니다. 계획 모드는 Codex에 해당 명령의 단축키가 지정돼 있어야 합니다. 12번을 이전에 직접 변경했다면 **키 매핑 → 12번 → 기본값 복원 → 저장**으로 새 대화를 배정할 수 있습니다.

**Claude Desktop**과 **Claude Code**도 내장 프로필에서 선택할 수 있습니다. Claude Code 슬롯과 권한 요청을 연결하려면 **기기 설정 → Claude Code 세션 훅 → 연결**을 누른 뒤 새 Claude Code 세션을 시작하세요. [Claude 키 배정 및 세션 설정](docs/key-mapping.md#codex와-claude)

## LED와 기기 설정

기본 슬롯 색은 **흰색이 유휴**, **파란색이 실행 중**, **주황색이 입력 대기**, **초록색이 아직 열어보지 않은 새 완료**입니다. T3에서 정리한 세션은 최근 슬롯에서 빠지고, 다음 순위의 대화가 빈자리를 채웁니다.

**기기 설정 → 세션 조명**에서 상태를 선택하고 슬롯 LED와 바닥 조명의 색·애니메이션을 각각 고른 뒤 **조명 저장**을 누릅니다. **기기 설정 → 기기**에서 전체 조명 밝기, 부저 볼륨, 자동 절전 시간을 설정합니다. 키 매핑 화면에서 1~13번 중 원하는 키를 누르고 **버튼 LED 설정**을 열거나, 기기 설정의 미리보기에서 해당 키를 선택하세요. 바닥 조명은 **바닥**을 선택합니다. **직접 설정**에서 256색 팔레트와 효과를 바꾸면 기기 그림에 미리 표시됩니다. 개별 조명은 모든 앱에 공통으로 적용됩니다. 밝기와 속도도 키마다 조절할 수 있습니다. 직접 설정을 끄면 세션 상태와 전송 가능 여부에 따른 자동 조명으로 돌아갑니다. **기기에 저장**을 눌러 반영합니다.

**기기 설정 → 펌웨어 → 업데이트**는 기존 키버스 설정을 유지합니다. **기기 공장 초기화**는 키버스 펌웨어를 유지하면서 기기의 설정과 Bluetooth 페어링을 지웁니다. 초기값은 전체 밝기 100%, 볼륨 50%, 절전 15분, 키와 바닥 조명 자동입니다. 초기화 후 Mac Bluetooth 설정에서 다시 페어링할 수 있습니다.

## 연결과 업데이트

| 증상 | 확인할 곳 |
| --- | --- |
| USB가 연결되지 않음 | 기기의 USB 유선 모드와 펌웨어 버전을 확인한 뒤 **다시 연결**을 누릅니다. |
| 앱에 단축키가 전달되지 않음 | 대상 앱을 열고 올바른 키맵이 선택됐는지 확인합니다. 메뉴 막대 아이콘 우클릭 → **권한 안내…**에서 손쉬운 사용 권한을 다시 확인합니다. |
| cmux에 ‘내부에서 시작된 프로세스만 연결할 수 있습니다’가 표시됨 | cmux의 소켓 제어 모드를 확인합니다. 내부 프로세스 전용 설정을 유지하려면 Keyberth를 종료하고 cmux 터미널에서 `/Applications/Keyberth.app/Contents/MacOS/MicroCompanion`을 실행한 뒤 터미널을 열어 둡니다. |
| 새 버전을 설치하고 싶음 | 응용 프로그램 폴더에 설치한 Keyberth는 자동으로 업데이트를 확인합니다. 바로 확인하려면 메뉴 막대 아이콘 우클릭 → **업데이트 확인…**을 선택합니다. 0.3.0 사용자는 최신 DMG로 한 번 수동 설치해야 합니다. |

## 0.8.0 변경 사항

- 시스템 동작에 macOS 영역 선택 스크린샷과 잠자기를 추가했습니다. 대상 앱 지정 그룹에서 마이크와 새 대화의 목적지를 선택할 수 있습니다.
- T3의 새 응답은 확인할 때까지 완료 상태로 표시합니다. ‘현재 대화 닫기 · 정리 (Settled)’를 실행하면 최근 슬롯을 다시 채웁니다.
- 설정 창을 닫으면 메뉴 막대에서 계속 동작하며 Dock 아이콘을 숨깁니다.
- 절전 해제 및 기기 재연결 때 최근 세션과 LED를 다시 동기화합니다. 동봉된 키버스 펌웨어 0.4.4는 연결이 유지되는 조명 대기 중 입력 요청과 완료 알림으로 조명을 깨웁니다. 무선 연결이 끊긴 깊은 절전에서는 기기를 먼저 깨워야 합니다.
- 기기 설정에서 읽기 전용 펌웨어 진단을 실행하고 단계별 작업 기록을 확인하거나 복사할 수 있습니다. 최근 50건을 Mac에 보관합니다.
